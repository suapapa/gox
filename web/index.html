Go version of npx

Run Go tools
without installation

Execute Go binaries directly from source repositories. Fast, cached, and version-aware. Just like npx, but for the Go ecosystem.

Get Started View on GitHub

Why gox?

No Global Bloat

Run any Go tool without cluttering your system's global bin directory.

Version Support

Execute specific versions using @v1.2.3 or @latest tags effortlessly.

Smart Caching

Built binaries are cached in your user directory for instant subsequent runs.

Installation

Scripted Install (Recommended)

One command to rule them all. Works on macOS and Linux.

curl -fsSL https://raw.githubusercontent.com/suapapa/gox/main/scripts/install.sh | sh

Manual Install

Using the standard Go toolchain.

go install github.com/suapapa/gox@latest

Make sure $(go env GOPATH)/bin is in your PATH.

Quick Usage

# Run a tool at latest version
gox owner/repo[@version] [args...]

# Example: Run golangci-lint
gox golangci/golangci-lint/v2/cmd/golangci-lint --version
